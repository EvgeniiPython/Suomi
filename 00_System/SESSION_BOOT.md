# SESSION BOOT

At the start of every lesson, execute this sequence:

1. Read `00_System/Current_State.md`.
2. Read `01_Today/Today.md`.
3. Read `02_Retention/TODAY_REVIEWS.md` and `02_Retention/Chunk_Review_Schedule.md`.
4. Identify all chunks whose **Next Review** is today or earlier.
5. Start with recall of due chunks **without hints**.
6. Use **Recall → Check → Correct → Retry** for misses.
7. Only after due reviews are checked, continue to the lesson's grammar / speaking focus.
8. Do not introduce new chunks until the due review set has been checked.
9. At the end of the lesson, update the session record, active chunks, progress metrics, and retention schedule.

## Important

The review table is date-driven. Always compare the current date to the **Next Review** field. A chunk is not considered automated just because it can be repeated after a prompt; it should also survive recall without hints, variation, and contextual transfer.
