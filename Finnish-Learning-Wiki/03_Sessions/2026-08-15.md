# 15 августа 2026 — Spoken D+3 / Professional Meeting Session

## Тема
Устный recall и перенос рабочих конструкций: договорённость с клиентом о встрече, необходимость выполнить действие после обеда, письмо/звонок клиенту и короткий рабочий эпизод.

## Формат
Speaking-First с Attempt → Hint → Self-correction → Repair → Second Output → Variation → Cold Recall → Transfer → Finnish Dialogue → Second Chance → Final Speaking Challenge.

Важно: это была расширенная spoken-сессия, но не полный 90-минутный протокол. Listening → Speaking с отдельным input и полноценный Final Recall из 3 новых предложений в этой сессии не были выполнены. Их не считать выполненными задним числом.

## Ход урока
1. Blind recall: пользователь восстановил `Me sovimme asiakkaan kanssa tapaamisesta ensi viikolle`, сначала с нестабильной формой `asiakaan`, затем исправил на `asiakkaan`.
2. Variation: `Me sovimme tapaamisesta huomiseksi.` — форма `huomiseksi` после repair была воспроизведена.
3. Cold recall: `Huomenna minun täytyy soittaa asiakkaalle lounaan jälkeen.` — после нескольких попыток правильная конструкция `täytyy + infinitive` была воспроизведена.
4. Transfer: новая ситуация с отправкой письма после обеда. Пользователь самостоятельно пытался собрать `Lounaan jälkeen minun täytyy lähettää sähköposti asiakkaalle`; потребовались подсказки по `lähettää`, `sähköposti` и порядку конструкции.
5. Finnish Dialogue: вопрос `Milloin soitamme asiakkaalle?` → ответ с `seitsemän...` / временем; диалоговый блок выполнен, но форма ответа требовала коррекции.
6. Final Speaking Challenge: пользователь самостоятельно рассказал 3–4 предложения о завтрашнем рабочем дне, используя `minun täytyy`, `lähettää sähköposti`, `asiakkaalle`, `lounaan jälkeen`, `sovimme tapaamisesta`.
7. Second Chance: при повторном recall четыре короткие конструкции были проверены; `lounaan jälkeen` и `Me sovimme tapaamisesta ensi viikolle` вышли, но `täytyy` и `lähettää` оставались менее стабильными.
8. Дополнительный контроль по протоколу: пользователь подтвердил, что не хочет добавлять новую метрику Fluency как отдельное изменение системы; протокол не изменён.

## Основные рабочие chunks
- `Sovimme asiakkaan kanssa tapaamisesta ensi viikolle.` — рабочий chunk, но падеж/форма ещё требуют автоматизации.
- `Me sovimme tapaamisesta huomiseksi.` — вариация с `huomiseksi`.
- `Minun täytyy soittaa asiakkaalle lounaan jälkeen.` — полезный рабочий chunk, пока Semi-active.
- `Lounaan jälkeen minun täytyy lähettää sähköposti asiakkaalle.` — пока Semi-active / guided production.

## Статус
### Active / Flexible
- `Sovimme asiakkaan kanssa tapaamisen ensi viikolla.` и вариации вокруг встречи — рабочая основа, доступна для variation.
- `Me sovimme tapaamisesta ensi viikolle.` — воспроизводится после подсказки/repair, поэтому пока не считать полностью Stable.

### Semi-active / Guided
- `Minun täytyy soittaa asiakkaalle lounaan jälkeen.`
- `Lounaan jälkeen minun täytyy lähettää sähköposti asiakkaalle.`
- `täytyy + infinitive`
- `lounaan jälkeen`
- `lähettää sähköposti`

Новые конструкции не повышать до Active без отдельного blind recall и transfer.

## Ошибки / repair
- `asiakaan` → `asiakkaan`.
- `täu tuu` / нестабильная форма → `täytyy`.
- `lähteä` → `lähettää` в значении «отправить».
- `kirjan` → `kirjeen` в предыдущем production; в сегодняшнем transfer целевая лексема была уточнена как `sähköposti`.
- `lounasta` / нестабильное произношение → `lounaan jälkeen`.
- `tapaamisesta` / `tapaamisen` / `tapaamisesta` требуют различать функцию конструкции, а не механически запоминать одну форму.

## Протокол: выполнено / не выполнено
- Retrieval / Recall: выполнено.
- Controlled Speaking + Variation: выполнено.
- Cold Recall: выполнено частично, с нестабильностью по `täytyy` и `lähettää`.
- Transfer: выполнено.
- Finnish Dialogue: выполнено в коротком формате.
- Error Repair + Second Chance: выполнено.
- Final Speaking Challenge: выполнено.
- Final Recall: **не выполнено полностью** — три разных новых предложения с главным pattern отдельно не запрашивались.
- Listening → Speaking: **не выполнено в полном формате**.
- Retention record: фиксируется этим отчётом и связанными файлами.

## Retention result
Основная профессиональная связка вокруг встречи стала доступнее для самостоятельной речи. `asiakkaan kanssa` и `tapaamisesta` всё ещё требуют точности. `täytyy + infinitive`, `lähettää` и `lounaan jälkeen` пока нельзя считать автоматизированными.

## Следующий шаг
- Начать следующее занятие с blind recall сегодняшних four target chunks.
- Проверить `täytyy` без подсказки.
- Отдельно вывести `lähettää sähköposti` и `lounaan jälkeen` в 2–4 вариации.
- Затем проверить `tapaamiseen` vs. `tapaamisesta` и старые retention-приоритеты.
- Если recall устойчив, выполнить listening → speaking с input около 30–60 секунд.
- Обязательно закрыть пропущенный Final Recall: 3 разных предложения с `täytyy + infinitive` в разных ситуациях.
