# Session 2026-08-15 — Hybrid Learning Trial

## Mode
**Speaking-First core + selected Learning OS upgrades**

## Goal
Проверить, улучшают ли Meaning Blocks, Mini Concept Network, Structured Error Log и Micro-Shadowing качество самостоятельной речи без перегрузки урока.

## Lesson Design
1. Retrieval
2. Listening → Big Picture → Meaning Blocks
3. Retell
4. Mini Concept Network
5. Variation
6. Transfer / Free Speaking
7. Error Repair
8. Optional Micro-Shadowing
9. Spoken Recall
10. Reflection

## Active Material
- `Minun ei tarvinnut siirtää tapaamista, koska kokous peruttiin.`
- `viime hetkellä`
- `asiakas tuli ajoissa`
- `Sovimme asiakkaan kanssa tapaamisesta ensi viikolla.`

## Trial Criteria
- Recall without full prompt
- Fluency under low pressure
- Transfer into a new situation
- Ability to explain the meaning blocks of a short input
- Whether a mini concept network helps retrieval rather than adding cognitive load

## Decision Rule
If an added mechanism does not improve spoken output, remove it from future lessons.

## Next Session
Start with delayed recall of today's active chunks, then use a short listening input with explicit meaning blocks and one small concept network. Add micro-shadowing only if rhythm/pronunciation needs it.
