# Spoken Recall Protocol

1. Выбрать знакомую ситуацию.
2. Дать пользователю говорить самостоятельно.
3. Не перебивать длинный рассказ.
4. Ждать «я закончил, говори».
5. Зафиксировать ошибки после output.
6. Дать минимальную подсказку.
7. Получить второй output.
8. Проверить, переносится ли паттерн в новый контекст.

Цель — автоматический доступ к чанкам в реальной речи, а не идеальное повторение за преподавателем.
