# Metrics And Audit

## Core Metrics

The lesson keeps three primary metrics unchanged:

```text
Recall / Fluency / Transfer
```

They remain the main conversational learning indicators.

## Evidence Score

For key patterns, add a 0–3 evidence score when a substantial lesson or audit provides enough evidence:

```text
0 = not yet
1 = assisted
2 = independent in familiar context
3 = flexible in changed context
```

This score does not replace Recall / Fluency / Transfer; it summarizes evidence strength.

## Auxiliary Signals

Record only when observable:

```text
Accuracy: correct first-attempt form / total target attempts
Repair rate: repaired attempts / target attempts
Contrast success: correct choices / mixed-choice attempts
Speaking state: automatic / hesitant / blocked
```

Never fabricate a numeric value. If the lesson did not measure it, write `not measured`.

## Biweekly Audit

Every 14 days, compare:

- mastery-state movement (active → consolidating → stable → dormant);
- repeated error counts and causes;
- Recall / Fluency / Transfer trends;
- 0–3 evidence scores for key patterns;
- mixed-choice contrast performance;
- long-term retention failures;
- transfer to new professional and personal situations.

## Decision Gate For New Chunks

```text
Recall + variation + transfer stable -> 2–3 new chunks may be introduced.
Recall broadly stable but 1–2 local errors -> repair first; then at most 1–2 new chunks.
Recall unstable or a priority trigger is active -> no new chunks.
```
