# Daily Speaking-First Protocol

## Цель
Главная цель ежедневной практики — как можно быстрее уменьшать задержку между мыслью и финской фразой.

Мы не измеряем успех количеством изученных слов. Основной показатель — способность самостоятельно понять ситуацию, сформулировать мысль, удержать паттерн, изменить его и использовать его в новом контексте.

## Базовый принцип

**Attempt → Check → Correct → Repair → Second Output → Variation Chain → Cold Recall → Transfer → Finnish Dialogue → Second Chance → Final Speaking Challenge → Final Recall → Retention**

Сначала пользователь пытается сказать сам. Объяснение и подсказка появляются после попытки, а не вместо неё.

## 90-минутная структура

### 0–10 мин — Retrieval
- Без подсказок вспомнить материал предыдущих занятий.
- Проверить 2–3 приоритетные ошибки.
- Воспроизвести несколько активных чанков.
- Не читать правильный ответ до собственной попытки.

### 10–25 мин — Listening → Speaking
- Короткий финский диалог или история.
- Первый проход: понять общий смысл без текста.
- Короткая проверка понимания своими словами.
- Второй проход: проверить детали, при необходимости с транскриптом.
- Выделить 2–3 полезных разговорных паттерна.
- Произнести их и затем пересказать смысл своими словами.
- Не превращать listening-блок в перевод всего текста.
- Постепенно увеличивать длину input примерно до 30–60 секунд, если понимание устойчиво.

### 25–35 мин — Encoding
- Выбрать 3–5 действительно полезных chunks из текущего материала; 2–3 из них могут прийти из listening.
- Разобрать смысловые части и грамматическую логику.
- Связать новые конструкции с уже известными.
- Не превращать этот блок в длительную лекцию по грамматике.

### 35–50 мин — Controlled Speaking
Для каждого основного pattern:
1. пользователь пытается произнести его без подсказки;
2. после успешного ответа получает **цепочку из 3–4 вариаций**;
3. менять по одному параметру: субъект, время, объект, обстоятельство, отрицание, вопрос или дополнительную информацию;
4. после примерно **3–5 упражнений** провести **Cold Recall** без подсказки и без готового финского предложения;
5. только после устойчивого recall переходить к transfer.

### 50–70 мин — Real Situation / Finnish Dialogue
- Получить реальную или правдоподобную ситуацию.
- Отвечать без заранее написанного текста.
- Преподаватель не перебивает длинный ответ.
- Если пользователь хочет исправления после рассказа, он говорит: **«я закончил, говори»**.
- При ступоре сначала дать минимальную подсказку, а не готовое предложение.
- После controlled practice переходить к короткому **диалогу на финском**: вопрос → ответ → follow-up → ответ.
- Русский используется только для краткого объяснения или подсказки, когда это действительно необходимо.
- По возможности использовать хотя бы один паттерн из listening-блока в новом контексте.

### 70–80 мин — Error Repair + Second Chance
Выбрать максимум 3 наиболее полезные ошибки.

Для каждой:
- ошибка;
- правильный pattern;
- минимальное объяснение;
- 2–4 вариации;
- короткий repair drill;
- **Second Chance позже в уроке** в новом предложении или ситуации.

Ошибка не считается закрытой после первого исправления. Она считается закрытой, когда пользователь позже воспроизводит правильную форму без подсказки. Если ошибка возвращается, она остаётся активной.

Не исправлять каждую мелкую ошибку. Приоритет — ошибки, которые мешают пониманию, повторяются или блокируют автоматический запуск конструкции.

### 80–87 мин — Final Speaking Challenge + Final Recall
- Пользователь получает реальную или правдоподобную ситуацию.
- Без подсказок самостоятельно рассказывает или объясняет её по-фински.
- Задача должна объединять несколько patterns текущего урока и по возможности один старый pattern.
- После этого выбрать главный pattern урока и попросить: **«Без подсказок назови 3 разных предложения, которые ты можешь построить с этой конструкцией.»**
- Предложения желательно делать в разных ситуациях: например работа, дом, планы.

### 87–90 мин — Retention / Lesson Record
- Зафиксировать активные patterns.
- Зафиксировать ошибки, которые получили Second Chance и требуют повторения.
- Определить даты следующего recall.
- Не заменять этот блок вопросами «что понял?» или длинной рефлексией.

## Правило помощи

Если пользователь ошибся:

**Attempt → Hint 1 → Self-correction → Hint 2 if needed → Answer only as last resort → Retry**

Подсказка должна быть минимальной и направлять к самостоятельному решению.

## Transfer

Задача transfer должна менять ситуацию или коммуникативную цель. Она не должна просто повторять русский перевод исходной фразы.

Хороший transfer требует самому понять, что знакомый pattern подходит к новой ситуации, и самостоятельно произвести финскую фразу.

## Что считается изученным

Материал не считается активным, если пользователь только:
- узнал его при чтении;
- понял объяснение;
- повторил его за преподавателем;
- правильно выбрал вариант из нескольких ответов;
- один раз правильно воспроизвёл его сразу после объяснения.

Для Active желательно:
- recall без подсказки;
- правильная структура;
- 3–4 вариации;
- cold recall после нескольких упражнений;
- transfer в новом контексте;
- использование в финском диалоге или свободной речи;
- успешный Second Chance после интервала;
- повторное извлечение через время.

## SRS

SRS используется выборочно для материала, который продолжает забываться после нормальной речевой практики.

Предпочтение отдаётся production cards с целыми chunks, а не изолированным словам.

## Правило новых chunks

Новые chunks не являются обязательной частью каждого урока.

- Устойчивый recall + variation + transfer → 2–3 новых chunks.
- Recall в целом устойчивый, но есть 1–2 локальные ошибки → repair, затем 1–2 новых chunks.
- Recall нестабилен или требует существенных подсказок → новых chunks не добавлять; продолжать repair, retry, variation и retention.

## Правило речи

Минимум половина 90-минутной сессии должна быть непосредственно связана с производством речи или подготовкой к нему.

Приоритет:
1. самостоятельная речь;
2. listening, которое превращается в output;
3. retrieval;
4. pattern practice;
5. grammar/deep processing;
6. SRS.

## Главный принцип

**Не изучать финский вместо разговора. Изучать именно то, что помогает говорить, и сразу превращать это в речь.**
