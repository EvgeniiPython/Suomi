# Mastery Criteria

## Purpose

A pattern is not mastered because it was copied correctly once. Mastery requires independent retrieval, delayed evidence, changed-context use, and resistance to competing forms.

## Mastery Ladder

| Status | Evidence required | Lesson action |
|---|---|---|
| **active** | New target, priority error, returned error, or reactivated weak pattern. | Teach, repair, and schedule retention. |
| **consolidating** | Correct second output in the lesson and at least one delayed rebuild. | Keep targeted +3 / +7 review and mixed-choice checks when relevant. |
| **stable** | Correct tomorrow, +3-day, and +7-day checks; at least one new personal context; competing forms pass one unlabeled mixed-choice check; no priority error in the evidence series. | Remove from active drill list; keep natural exposure and periodic sampling. |
| **dormant** | Independent use in at least two later relevant outputs without a key error or prompt. | No dedicated drill; sample through normal conversation and delayed retention. |

## Score Within a Lesson

Use a simple 0–3 evidence score for each key pattern when the lesson is substantial:

```text
0 = not yet
1 = assisted / only after model or heavy hint
2 = independent in a familiar context
3 = flexible in a changed context
```

Do not treat 3/3 in one lesson as stable mastery. Stable requires delayed evidence.

## Required Evidence Dimensions

For a speaking-relevant pattern, track:

```text
Recall     = retrieved without a model
Accuracy  = correct form and task meaning
Fluency   = automatic / hesitant / blocked
Transfer  = independently selected in a changed context
Contrast  = survives an unlabeled mixed-choice check when competing forms exist
```

## Evidence By Material Type

### Chunk or phrase

```text
Retrieve from memory.
Use in a changed personal context.
Say it aloud when speaking-relevant.
Record automatic / hesitant / blocked.
```

### Grammar pattern

```text
Choose the form in several examples.
Contrast it with the nearby competing form.
Use it correctly in free output.
Pass one unlabeled mixed-choice check.
```

### Vocabulary

```text
Recall without a cue.
Use in at least two self-created contexts.
Do not count recognition in a text as active vocabulary.
```

## Status protection and error granularity

A single isolated mistake does not automatically move a pattern backward.

Classify the error before using it as mastery evidence:

- conceptual/grammar or contrast error: may affect mastery/trigger when repeated;
- retrieval/form slip: observe recurrence; one slip does not automatically downgrade conceptual mastery;
- spelling/surface slip: does not downgrade grammar mastery and does not create a grammar trigger when the intended construction is clear.

Stable or consolidating patterns should be reactivated only when repeated meaningful evidence shows loss of retrieval, a speaking blocker, or recurring confusion with a competing form.

## Acquisition eligibility

Mastery status and new-material eligibility are separate decisions:

```text
review_priority
    = how strongly existing material needs review

acquisition_eligibility
    = whether new material may be introduced
```

A pattern may remain **consolidating** while acquisition is allowed. Reaching `stable` or 100% error-free performance is not required before new chunks/patterns are introduced.

## Reactivation

Move a stable or dormant item back to active if:

```text
A key error returns in a relevant task.
The learner cannot retrieve it after a normal delay.
A speaking blocker appears.
The learner confuses it with its contrast form.
```

## Recording Rule

At lesson closing, record only meaningful status changes:

```text
active -> consolidating
consolidating -> stable
stable -> dormant
stable/dormant -> active + reason
```

Do not create a status change for every single correct answer.

## Review Rule

Use this page during lesson closing, retention review, or biweekly audit. Do not open it for every fast recall task.
