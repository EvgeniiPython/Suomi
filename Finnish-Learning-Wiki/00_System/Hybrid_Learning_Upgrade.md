# Hybrid Learning Upgrade

## Назначение

Этот файл фиксирует выбранные элементы из `Finnish Learning OS Master v3.0`, которые усиливают нашу существующую Speaking-First систему.

**Наша система остаётся основной.** Архив используется как набор вспомогательных механизмов, а не как новая архитектура.

## Что заимствуем

### 1. Meaning Blocks
В listening сначала определяем:
- что произошло;
- кто участвует;
- почему;
- что произошло потом.

Не переводим весь текст.

### 2. Mini Concept Network
Для 1–2 ключевых chunks строим маленькую сеть связанных ситуаций и форм.

Пример:
`Minun ei tarvinnut...` → `siirtää tapaamista` → `kokous peruttiin` → `viime hetkellä` → `asiakas tuli ajoissa`.

### 3. Structured Error Log
Повторяющаяся ошибка:
`Error → Correct Pattern → Reason → Missing Concept → Repair → Variation → Transfer → Review Date`.

### 4. Micro-Shadowing
2–5 минут на 2–3 предложения из текущего listening. Использовать только если это улучшает ритм, произношение или автоматизм.

### 5. Recall / Fluency / Transfer
Это три главные метрики для активных chunks.

### 6. Weekly Review
Раз в неделю смотреть на изменение активных chunks, повторяющиеся ошибки, listening→speaking и перенос в реальные ситуации.

### 7. Reflection
2–3 минуты в конце полного занятия:
- что стало легче;
- что нестабильно;
- что применить в реальной жизни.

## Что НЕ импортируем

Не делаем обязательными:
- Bloom × 6 для каждого урока;
- большие vocabulary networks;
- 8–12 новых слов за занятие;
- длинный deep-processing блок;
- 120-минутный формат по умолчанию;
- большое количество административных метрик.

## Экспериментальный режим

В следующих 2–3 занятиях сравниваем обычный и hybrid-режим по трём вопросам:

1. Стало ли легче вспоминать chunks?
2. Улучшился ли перенос из listening в самостоятельную речь?
3. Стала ли речь более беглой без увеличения когнитивной нагрузки?

Если новый элемент не улучшает output, он удаляется.
