## Текущий фокус
Профессиональный разговорный финский: договорённости о встречах, перенос времени, объяснение причин, возможное опоздание и описание прошедшего события. Технический рабочий финский (3D-модель, чертежи, проверка и исправления) остаётся активным вторым контекстом.

Учебное ядро: **Attempt → Check → Correct → Repair → Second Output → Variation → Transfer → Spoken Recall → Retention**.

Текущий усиленный режим: **Listening → Understanding → Meaning Blocks → Retell → Variation → Transfer**, с маленькой concept network, структурированным error log и optional micro-shadowing. Эти элементы поддерживают Speaking-First, но не заменяют его.
