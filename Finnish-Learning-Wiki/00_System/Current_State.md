# Current State

**Последнее занятие:** 21 августа 2026

## Текущий уровень
Finnish A2 with growing A2+/B1 control in familiar personal and professional topics.

## Текущий фокус
Профессиональный разговорный финский: необходимость выполнить действие (`minun täytyy + infinitive`), звонок/e-mail клиенту, обстоятельства времени (`lounaan jälkeen`), договорённость о встрече (`sovimme tapaamisesta`) и автоматизация отрицания/конкурирующих форм.

Учебное ядро:

**Attempt → Check → Correct → Repair → Second Output → Variation → Cold Recall → Transfer → Finnish Dialogue → Second Chance → Final Speaking Challenge → Final Recall → Retention**

## System Upgrade Active — 18.08.2026

В работу добавлены механизмы из архивной Learning OS, без изменения Speaking-First ядра:

```text
Mastery Ladder: active -> consolidating -> stable -> dormant
0–3 Evidence Score: not yet / assisted / familiar-independent / changed-context-flexible
Error Cause: encoding / retrieval / contrast_selection / processing_load / pronunciation_blocker
Unlabeled Mixed Choice Check for competing forms
Biweekly audit of status movement and retention
Quantitative auxiliary signals only when actually measured
```

Правило: исправление сразу после подсказки не считается delayed mastery.

## Главные ошибки
- `täytyy` + личная форма → после `täytyy` нужен infinitive.
- `lähettää` vs. `lähteä`.
- `en soittaa` → `en soita`.
- `en lähetä` vs. `lähetän`.
- `sähköpostia` vs. `sähköpostin` по контексту.
- `ensi viikolla` vs. `ensi viikolle`.
- `tapaamiseen` vs. `tapaamisesta`.
- `kotiin` vs. `kotona` по направлению/местонахождению.
