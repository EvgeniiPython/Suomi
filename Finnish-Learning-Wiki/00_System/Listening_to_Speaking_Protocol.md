# Listening → Speaking Protocol

## Цель
Использовать аудирование не как пассивное потребление языка, а как источник материала для самостоятельной речи.

Главный цикл:

**Listen → Understand → Recall → Notice → Retell → Use → Delayed Recall**

## Базовый формат

### 1. First Listen — общий смысл
- Короткий диалог или история на финском.
- Сначала слушать без текста и без остановок.
- Цель — понять ситуацию, участников, основное событие и намерение.
- Не требовать понимания каждого слова.

### 2. Comprehension Check
Пользователь своими словами отвечает:
- Что произошло?
- Кто что сделал?
- Почему?
- Что будет дальше?

Если понимание слабое, повторить фрагмент, но не давать полный перевод сразу.

### 3. Second Listen — проверка деталей
- Прослушать ещё раз.
- При необходимости использовать транскрипт.
- Отметить только действительно полезные или повторяющиеся конструкции.

### 4. Notice
Выбрать **2–3 полезных chunks**, а не выписывать весь новый словарь.
Приоритет:
- разговорные конструкции;
- конструкции, связанные с текущим рабочим контекстом;
- формы, которые уже встречались и теперь получили новый контекст;
- элементы, которые можно быстро перенести в собственную речь.

### 5. Retell
Текст закрывается.
Пользователь пересказывает услышанное своими словами, не пытаясь дословно воспроизвести историю.

### 6. Personal Transfer
Из 2–3 выбранных конструкций пользователь создаёт собственные фразы и использует их в новой ситуации.

### 7. Error Repair
Если возникли ошибки, применяется обычный цикл урока:

**Error → Correct Pattern → Variation → Transfer**

Не исправлять каждую мелочь. Максимум 3 приоритетные ошибки.

### 8. Delayed Recall
Полезные конструкции возвращаются позже в уроке или на следующем retention-интервале без исходного аудио.

## Что фиксируется в Wiki
Для каждого значимого аудио/истории при необходимости фиксировать:
- тему/ситуацию;
- уровень сложности;
- насколько хорошо понят общий смысл;
- 2–3 активных chunks;
- ошибки понимания или производства;
- дату следующего recall.

Не превращать Wiki в каталог всех услышанных слов.

## Критерий успешного listening
Listening считается полезно освоенным, если пользователь может:
1. понять общий смысл без текста;
2. восстановить ключевые детали;
3. пересказать содержание своими словами;
4. использовать хотя бы одну полезную конструкцию в новом контексте;
5. вспомнить её позже без исходного аудио.

## Интеграция с основным уроком
Listening не заменяет speaking-first цикл. Он подпитывает его:

**Listening → Notice → Speaking → Repair → Variation → Transfer → Retention**

По умолчанию использовать короткие материалы, чтобы основное время оставалось за самостоятельной речью.
