# Candidate Chunks

## Purpose

This file is a staging bank for potentially useful Finnish chunks, expressions, grammar patterns, and vocabulary that have been encountered but have not yet been selected for active study.

A candidate is **not** automatically an active learning target.

## Lifecycle

```
candidate → selected → active → consolidating → stable → dormant
```

- **candidate** — discovered and recorded, but not yet selected.
- **selected** — chosen as a likely useful next target.
- **active** — currently practiced actively.
- **consolidating / stable / dormant** — follow the normal mastery lifecycle.

## Selection rules

A candidate may be promoted when it is useful for real communication, reusable, sufficiently clear, appropriate for the current level, and worth the cognitive cost.

Do not promote candidates merely because they appeared once.

## Candidate vs Active Vocabulary

Candidate_Chunks.md contains potential future material.

Active_Vocabulary.md contains material selected for active learning.

**Never add a candidate to Active Vocabulary automatically.**

## Interaction with acquisition eligibility

Candidate accumulation never blocks acquisition. Review priority and acquisition eligibility remain separate.

A weak or consolidating old chunk can remain under review while a useful candidate is promoted.

If acquisition is blocked by a meaningful conceptual failure or active grammar trigger, candidates remain candidates.

## Discovery sources

Candidates may come from stories, listening, Finnish dialogue, user-generated speech, corrections, real professional situations, recurring vocabulary, and useful grammar contrasts.

## Lesson behavior

When new material appears:

1. Do not immediately add everything to active study.
2. Record potentially useful items here.
3. Determine what the user already knows.
4. Promote only selected high-value items.
5. Introduce a small number of new active targets according to Lesson Protocol and acquisition eligibility.
6. Keep the remaining candidates available for future selection.

The candidate bank is a **reservoir**, not a second active vocabulary list.
