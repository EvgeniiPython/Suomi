# Retention Rules

## Core Rule

```text
Recall first. Check later.
```

## Default Schedule

```text
Tomorrow: rebuild from memory + one small variation.
+3 days: transfer to a new context; use an unlabeled mixed-choice prompt when forms compete.
+7 days: free mini-text or spoken answer with independent form selection.
+14 days: delayed sampling of unstable patterns.
+30 days: long-term sampling; stable/dormant items are sampled without warning.
```

Use the shortest schedule that matches the current mastery state; do not mechanically drill every item at every interval.

## Unannounced Sampling

Previously learned patterns may also be sampled without warning during normal `FULL_LESSON` activities. This is an additional check of spontaneous retrieval, not a separate retention schedule.

Use 1–3 samples when appropriate, selecting primarily from:

```text
CONSOLIDATING → more frequent
STABLE → occasional
DORMANT → rare
```

Do not repeatedly sample the same item in consecutive lessons. The learner should not be told which pattern is being tested before responding.

Classify the spontaneous result as:

```text
AUTOMATIC
HESITANT
REPAIRABLE
FAILED
```

Repeated main-lesson practice of the same target is not independent sampling evidence.

Interpret sampling together with mastery and retention evidence:

```text
AUTOMATIC + correct → evidence of retained accessibility
HESITANT → continue monitoring; do not promote on this evidence alone
REPAIRABLE → keep under consolidation and sample again later
FAILED → targeted retention/repair required
```

## Mixed Choice Rule

Do not name the target grammar before a delayed transfer check. Mix 3–5 prompts that require choosing among nearby forms, for example:

```text
personal present / personal past
passive present / passive past
location / direction
affirmative / negative
total object / ongoing object
```

The learner must choose from meaning and context, not from a visible grammar label.

## Spoken Recall

For speaking-relevant patterns:

```text
Read aloud -> close text -> say from memory -> mark automatic / hesitant / blocked.
```

## Dormant Sampling

When a pattern reaches `dormant`, stop dedicated drilling. Sample it periodically in normal conversation or a mixed task.

```text
automatic + correct -> remain dormant
hesitant -> return to consolidating + review within 7 days
error or wrong contrast -> return to active + create targeted repair
```

## Review Procedure

```text
1. Try from memory.
2. Speak or write before checking.
3. Verify grammar, task meaning, naturalness.
4. Classify any repeated error by cause.
5. Repair only the priority pattern(s).
6. Re-test in a changed context.
7. Update mastery state and next retention date.
```

## Retention Completion Gate

A retention task is not complete merely because the learner repeated a corrected sentence. For a priority pattern, completion requires either:

```text
correct independent delayed output
or
an explicit scheduled next check because evidence is still weak.
```
