# Pattern Practice Protocol

## Цель
Превратить полезную разговорную конструкцию из понятой фразы в автоматически доступный речевой pattern.

## Основной цикл

**Attempt → Repair if needed → Variation Chain → Cold Recall → Transfer → Finnish Dialogue → Second Chance → Delayed Recall**

## Pattern → Variation Chain → Cold Recall → Transfer

1. Выбрать полезную фразу из реальной ситуации.
2. Понять её общий смысл и смысловые части.
3. Пользователь пытается воспроизвести pattern без подсказки.
4. Если есть ошибка — сначала hint и самостоятельная коррекция; готовый ответ только как последняя ступень помощи.
5. После успешного ответа сделать **3–4 последовательные вариации**, меняя по одному параметру:
   - субъект;
   - время;
   - объект;
   - обстоятельство;
   - отрицание;
   - вопрос;
   - причина или дополнительная информация.
6. После примерно **3–5 упражнений** провести **Cold Recall** без подсказки и без готового финского предложения.
7. Если recall устойчив — дать задачу **Transfer** в новой ситуации.
8. Затем использовать pattern в коротком финском диалоге.
9. Если pattern возник из ошибки, вернуть его позже через **Second Chance** в новом контексте.
10. Проверить delayed recall через несколько дней.

## Transfer

Transfer не должен быть просто переводом исходной фразы с заменой одного слова.

Хорошая задача:
- меняет ситуацию;
- меняет коммуникативную цель;
- не показывает готовую финскую конструкцию;
- заставляет пользователя самостоятельно распознать и применить знакомый pattern.

## Finnish Dialogue

После controlled practice pattern используется в мини-диалоге:

**Question → User answer → Follow-up → User response**

Диалог по возможности ведётся на финском. Русский используется только для краткой подсказки или объяснения.

## Second Chance

Если pattern был проблемным, его нельзя считать освоенным сразу после правильного исправления.

Формат:

**Error → Correct Pattern → Variation → Delayed Re-test → New Context**

Ошибка считается закрытой, когда пользователь позже воспроизводит правильную форму без подсказки. При повторной ошибке pattern возвращается в активный Error Log.

## Приоритет chunks

Предпочтение отдаётся не изолированным словам, а готовым или полуготовым конструкциям, которые можно использовать в разговоре.

Например, вместо изучения только `myöhästyä` полезнее активировать:

> Saatan myöhästyä vähän.

Затем:

> Saatan myöhästyä, koska...

> En ehkä ehdi ajoissa.

## Критерий автоматизации

Чанк считается активным, когда пользователь может:
- запустить его без перевода с русского;
- удержать структуру;
- сделать 3–4 вариации;
- успешно пройти cold recall после нескольких упражнений;
- изменить контекст;
- использовать его в новом контексте;
- применить его в финском диалоге или свободной речи;
- пройти Second Chance после временного интервала;
- вспомнить после более длительного интервала.

## Что не считать автоматизацией

Не считать достаточным:
- чтение чанка;
- понимание перевода;
- повторение вслед за преподавателем;
- одно правильное воспроизведение сразу после объяснения;
- правильный ответ с несколькими вариантами на выбор.

## Связь с ошибками

Если pattern появился из ошибки, использовать цикл:

**Error → Hint → Self-correction → Correct Pattern → Variation Chain → Cold Recall → Transfer → Second Chance → Delayed Recall**

Приоритет отдаётся тем patterns, которые дают большой перенос на другие ситуации.
