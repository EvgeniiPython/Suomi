# Pattern Practice Protocol

## Цикл чанка
1. Выбрать полезную фразу из реальной ситуации.
2. Разбить на смысловые части.
3. Произнести каждый чанк.
4. Соединить в целое.
5. Воспроизвести без подсказки.
6. Сделать вариацию.
7. Перенести в новый контекст.
8. Проверить через интервалы.

## Критерий автоматизации
Чанк считается активным, когда пользователь может запустить его без перевода с русского, удержать структуру, изменить контекст и использовать его в свободной речи.
