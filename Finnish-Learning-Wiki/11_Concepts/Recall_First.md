# Recall First

Первым действием на уроке является самостоятельное извлечение материала из памяти.

## Цикл
**Recall → Check → Correct → Retry**

Если пользователь вспомнил — не нужно сразу давать правильный ответ; нужно проверить точность и затем дать вариацию.

Если возник ступор — дать минимальную подсказку, получить исправленный output и снова проверить recall.
