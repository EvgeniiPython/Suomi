# Contrast Cards

Purpose: force form selection from meaning rather than from a visible grammar label.

## Current Priority Set

### 1. Affirmative vs negative

```text
Soitatko asiakkaalle tänään?
→ soitan / en soita
```

```text
Lähetätkö sähköpostin tänään?
→ lähetän / en lähetä
```

### 2. Lähettää vs lähteä

```text
Mitä teet sähköpostin kanssa?
→ lähetän sähköpostin

Mitä teet työn jälkeen?
→ lähden töistä / lähden kotiin
```

### 3. Sähköpostia vs sähköpostin

```text
En lähetä sähköpostia.
Lähetän sähköpostin huomenna.
```

### 4. Lounaan jälkeen / before-action selection

```text
Milloin lähetät sähköpostin?
→ huomenna lounaan jälkeen
```

### 5. Tapaamisesta / tapaamiseen

```text
Sovimme tapaamisesta.
Menemme tapaamiseen.
```

## Rule

Do not tell the learner which contrast is being tested before the prompt. Mix cards with the same topic but different required forms.

## Completion

A contrast is considered strong only after the learner succeeds in an unlabeled mixed-choice check on a delayed date.
