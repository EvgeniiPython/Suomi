# Finnish Learning Wiki

Это Wiki для системного обучения финскому языку с упором на разговорную автоматизацию и профессиональную речь.

## Как начинать урок
Скажи: **«Начинаем урок. Используй SESSION_BOOT.»**

Преподаватель сначала читает текущее состояние, active focus и retention, затем проводит retrieval/cold recall.

## Основной цикл

**Attempt → Check → Correct → Repair → Second Output → Variation → Cold Recall → Transfer → Finnish Dialogue → Second Chance → Final Speaking Challenge → Final Recall → Retention**

## Unannounced Recall Sampling

Во время `FULL_LESSON` периодически проверяются 1–3 ранее изученных patterns/chunks, которые не являются главным фокусом текущего урока. Выбор делается без предупреждения и с большим вниманием к `CONSOLIDATING`, реже к `STABLE` и `DORMANT` items. Цель — проверить спонтанный recall вне недавно отработанного материала.

## Усилители системы

- Mastery Ladder: `active → consolidating → stable → dormant`
- Evidence Score: `0–3`
- Error Cause: `encoding / retrieval / contrast_selection / processing_load / pronunciation_blocker`
- Unlabeled Mixed Choice для конкурирующих форм
- Recall / Fluency / Transfer как основные метрики
- Accuracy / Repair Rate / Contrast Success только при реально измеренных данных
- Biweekly audit и dormant sampling

## Текущий фокус
Профессиональный финский: 3D-модель, osapiirustukset, kokoonpanopiirustukset, проверка чертежей, исправления и производство.

## Текущие ключевые patterns
`minun täytyy + infinitive`, `en soita / soitan`, `en lähetä / lähetän`, `lähettää / lähteä`, `sähköpostia / sähköpostin`, `lounaan jälkeen`, `sovimme tapaamisesta`.

## Следующая грамматическая цель
`minun ei tarvinnut`, затем imperfekti vs. perfekti и падежи дополнения — только после устойчивого recall + variation + transfer по текущим зонам внимания.
